Wallpaper Cover SR 0.3.1（Windows x64 便携版）

1. 完整解压，运行 WallpaperCoverSR.exe。
2. 正常播放音乐、应用原壁纸。原壁纸应当已能读取 Windows 歌曲封面。
3. 开启“启用封面增强”和“优先使用网易云高清原封面（联网）”。
4. 高清原图直接显示，不经过 AI 超分；最长边超过1024时缩小后发布。
5. 高清原图获取失败时，使用下方 2× / 3× / 4× 超分倍率作为回退。

无需网易云登录或 cookie，不通过歌名在线搜索。只读本地播放队列取得官方图片地址，再与实际缩略图核对；不确定时回退。切换壁纸无需重新适配。
关闭高清选项可使用离线超分。恢复播放器封面按钮会关闭整个增强功能。

关闭窗口只是收起到托盘。双击托盘或再次运行程序可打开设置。
需要开机启动时勾选“登录 Windows 时在后台启动”；Wallpaper Engine 自启动单独设置。

高清取图已验证网易云 Windows 3.1.41.205529，依赖本地队列格式。其他客户端版本或播放器无法匹配时使用系统封面流程。壁纸需从 Windows 当前媒体会话取图；固定只读网易云时需改为自动或允许 WallpaperCoverSR。网页壁纸尚未完成实机验证。

回退超分使用官方 Real-ESRGAN NCNN/Vulkan，需要支持 Vulkan 的显卡驱动。无需 Python 或 CUDA。只有新低清封面处理时短暂占用 GPU，完成后释放。

升级：先退出旧程序，再用新便携包替换，应用创意工坊原壁纸即可。
设置/日志/缓存：%LOCALAPPDATA%\WallpaperCoverSR。
卸载：取消开机启动、托盘退出、删除软件目录；用户数据可自行清理。
